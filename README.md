# Minimalist Portfolio

A clean, minimalist portfolio website with a resume-like structure.

## Features

- Minimalist design with resume-like layout
- Sans-serif typography
- Animated white background gradient
- Smooth scrolling
- Fully responsive
- No border radius (sharp, clean edges)
- Print-friendly styles

## Customization

Edit `index.html` to update:
- Your name and title
- Contact information
- Social links (GitHub, LinkedIn, etc.)
- Work experience
- Projects
- Skills
- Education

The CSS file (`style.css`) contains all styling and animations.

## Deployment

This portfolio is configured to automatically deploy to GitHub Pages when you push to the main branch or the current feature branch.

### Setting up GitHub Pages

1. Go to your repository settings
2. Navigate to "Pages" in the left sidebar
3. Under "Build and deployment", select "GitHub Actions" as the source
4. Push your changes and the site will be deployed automatically

Your site will be available at: `https://[username].github.io/[repository-name]`

## Local Development

Simply open `index.html` in your web browser to preview the portfolio locally.
